Hermes MUIA

Política de privacidad

Cómo utiliza y protege Hermes MUIA los datos de Google Calendar.

Inicio Condiciones de uso

Ámbito

Hermes MUIA es una aplicación privada, autoalojada y destinada a un único usuario. Esta política se aplica a la integración de esa aplicación con Google Calendar.

Datos a los que accede

La aplicación puede acceder a la información necesaria para gestionar eventos:

  • título, descripción y ubicación;
  • fecha, hora, zona horaria y recordatorios;
  • identificador, estado y enlace del evento.

La aplicación usa el permiso limitado https://www.googleapis.com/auth/calendar.events. No solicita permiso para administrar calendarios ni su configuración de uso compartido.

Finalidad

Los datos se utilizan exclusivamente para:

  • mostrar y buscar eventos solicitados por el usuario;
  • crear, actualizar o eliminar eventos bajo su control;
  • sincronizar recordatorios académicos gestionados por Hermes;
  • detectar y resolver errores técnicos de la integración.

Tratamiento y comunicación

Los datos se procesan en la infraestructura privada del usuario. El contenido estrictamente necesario puede ser enviado al proveedor de inferencia configurado para comprender una petición o redactar una respuesta. No se vende, se alquila, se usa para publicidad ni se comparte con intermediarios de datos.

Hermes MUIA no utiliza los datos obtenidos de las APIs de Google para desarrollar, mejorar o entrenar modelos generalistas de inteligencia artificial o aprendizaje automático.

El uso de información recibida de las APIs de Google se ajustará a la Política de Datos de Usuario de los Servicios de API de Google, incluidos sus requisitos de Uso Limitado.

Almacenamiento y conservación

Las credenciales OAuth se guardan en el entorno privado del usuario con acceso restringido. Se conservan mientras la integración esté activa o hasta que sean revocadas o reemplazadas. Hermes puede guardar identificadores y estados mínimos de los eventos que gestiona para evitar duplicados y reconciliar cambios. El historial técnico local se limita a lo necesario para operar y diagnosticar la aplicación.

Seguridad

La aplicación aplica permisos de archivo restrictivos, limita el acceso de Google al ámbito mínimo necesario y evita incluir credenciales en el código o en esta web pública.

Control y eliminación

El usuario puede revocar el acceso desde la sección de conexiones con terceros de su cuenta de Google. También puede eliminar las credenciales y los registros locales desde la instalación privada de Hermes. La revocación impide nuevas consultas o modificaciones en Google Calendar.

Contacto

Las consultas sobre esta política pueden realizarse mediante el apartado de incidencias del repositorio público que aloja esta página.
